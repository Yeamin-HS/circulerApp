# ADR-003: CV handling and v1 scope
Status: accepted (provisional, owner to confirm) · 2026-11-14
Decisions:
- The CV file is deleted after the profile is confirmed; only the structured profile is stored.
- Only confirmed profiles feed eligibility.
- Admin shared circulars move to v1.1; v1 handles personal uploads only.
- v1 (days 1–3) and v1.1 (days 4–5) split as in ROADMAP.md.
Why: less personal data held (PDPO 2025); a smaller v1 that can actually ship.
